# Nova 無限流面板

SillyTavern 第三方擴充。管理無限流副本的狀態（副本、幕、線索、卡司、日曆、背包、辭典、世界線帳本），依模式把規則與資料注入給 AI，並把真相、真名、好感等封存資訊藏起來。

## 安裝

1. 把這個資料夾裡的檔案上傳到一個 **公開** 的 GitHub repository（檔案要放在 repository 最外層，不要多包一層資料夾）。
2. 在 SillyTavern 上方工具列點「擴充功能」（積木圖示）→「安裝擴充功能」。
3. 貼上 repository 網址（例如 `https://github.com/你的帳號/nova-infinite`），按安裝。
4. 重新整理頁面。

## 打開面板

- 輸入框左邊的魔杖選單 →「無限流面板」
- 或擴充功能設定 →「Nova 無限流面板」→「打開無限流面板」

## 基本流程

1. 開一個新聊天，面板模式切到「白域大廳」，跟無語互動、選副本。
2. 選好副本後，開一個新聊天，模式切到「副本開局」，填種子卡，送出第一則訊息。
3. AI 會在回覆末尾輸出 `<inf_open>` 標籤，插件自動讀取、從畫面移除，並切到「副本進行中」。
4. 之後 AI 每回合以 `<inf>` 標籤回報變化（線索、進度、日期、讓渡……），插件自動更新。
5. 副本結束時，AI 輸出 `instance_end`，插件寫入帳本，切到「結算」。

## 檔案

- `manifest.json`：擴充資訊
- `index.js`：主程式
- `rules.js`：預設規則與標籤格式（第一次載入後會複製到設定中，之後在面板「規則」分頁修改）
- `style.css`：面板樣式
